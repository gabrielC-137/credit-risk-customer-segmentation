# Power BI Dashboard

This directory contains the Power BI dashboard developed for the credit risk analysis project.

---

## File

- **credit_risk_dashboard.pbix**

---

## Overview

The dashboard provides an interactive visualization of customer credit behavior, segmentation, and default risk.

It complements the machine learning analysis by translating complex results into business-friendly insights.

---

## Key Features

- Customer segmentation visualization
- Credit limit distribution analysis
- Payment behavior trends
- Default risk indicators
- Cluster comparison analysis

---

## Purpose

The dashboard is designed to support decision-making by:

- Identifying high-risk customer segments
- Understanding financial behavior patterns
- Enabling interactive exploration of key metrics

---

## Notes

- The data was preprocessed using Power Query before being analyzed in Python.
- The dashboard integrates results from clustering and predictive modeling.

This component bridges the gap between technical analysis and business intelligence.
