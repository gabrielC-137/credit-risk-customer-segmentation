# Raw Data

This directory contains the original, unprocessed dataset used in the project.

---

## File

- **uci_credit_card_dataset.csv**

---

## Description

This dataset is based on the UCI Credit Card dataset and includes information about customer demographics, credit limits, billing amounts, payment history, and default behavior.

The data in this folder represents the **initial state of the dataset**, before any cleaning, transformation, or feature engineering was applied.

---

## Purpose

The raw dataset is preserved to:

- Maintain data integrity and reproducibility  
- Provide a reference to the original data source  
- Allow reprocessing and validation of transformations  

---

## Notes

- No modifications have been made to this dataset
- It may contain unnecessary columns (e.g., ID)
- Data preprocessing is performed in the analysis pipeline

This dataset serves as the starting point for all subsequent data processing and analysis steps.
